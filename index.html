Offline-First Architecture & Camp Hub Guide

Designed to operate reliably in remote villages with zero external internet access.

Mode A: Camp Local Wi-Fi

A battery-powered camp hub laptop or Raspberry Pi runs this system. Patients and doctors connect to the camp Wi-Fi router (no SIM or broadband needed). All updates sync over the local network.

Mode B: Device Offline PWA

Once loaded, the patient's token is saved locally in browser storage (IndexedDB/LocalStorage). Even if the phone disconnects or the user refreshes, their token and position remain intact.

Mode C: Cloud Sync Ready

When the camp hub reconnects to cellular data or broadband in the evening, all consultation logs and analytics can be pushed to cloud databases with a single export.

3-Step Camp Morning Setup

  1. Turn on Wi-Fi Router / Hotspot: Set SSID to Camp-WiFi-Free with open access (no password).
  2. Open MediQueue on Hub Laptop: Start the local server or open this HTML app. Connect the projector or display TV for the Public Board.
  3. Print Camp QR Posters: Click "Print Poster" button above to generate printable A4 posters with QR codes and post them at registration gates and waiting tents.
